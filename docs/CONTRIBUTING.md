# Contributing

Thank you for helping improve safe, accountable public-safety robotics.

## Before contributing
- Read the README and safety requirements.
- Keep proposals within the non-weaponized, human-supervised mission.
- Do not submit personal, confidential, classified or unlawfully obtained information.
- Never include secrets, credentials, private keys, access tokens or real personal data.

## Changes
- Explain the problem and intended public benefit.
- Identify safety, privacy, cybersecurity, legal and maintenance implications.
- Distinguish measured facts from assumptions and targets.
- Include tests or evidence for claimed behavior.
- Document known limitations and failure modes.

## Review
Safety-sensitive changes require review by an appropriate independent reviewer. A successful software test is not proof of operational safety. No code contribution authorizes procurement, field trials or production deployment.

## Out of scope
Weaponization, targeting, autonomous force, covert surveillance, evasion of oversight and unlawful data collection are not accepted.
